# Cicada 合规复核工作台

桌面端交互原型，使用虚构通话和演示规则展示从 AI 初筛到人工复核、提交和记录追溯的流程。

## 页面

- 复核队列
- 通话复核
- 提交复核
- 处理记录

打开 `canvas.json` 可在兼容 Design Component 的画布编辑器中查看四个画板。各页面源码位于同目录的 `*.dc.html` 文件。

## 演示路径

打开 `CALL-DEMO-001`，检查规则 `DEMO-02` 的否定语境，驳回提示并填写理由；处理其余两项后提交复核，最后查看处理记录。

所有通话、转录、规则、AI 结果和人员信息均为模拟数据。播放器没有真实音频，导入入口不上传或识别录音；本原型也没有正式权限控制或持久化审计存储。
